# Yahoo! お得日カレンダー v0.5.0

iPhone / Windows 共通の GitHub Pages + GitHub Actions PWA。PC常駐不要です。

## v0.5.0 追加点
- Windows/大型画面では「左: 月間カレンダー / 右: 日別詳細」の2ペイン表示。
- 右側の日別詳細はスクロール時も追従するsticky表示。
- 選択中の日付を青枠で明示。月移動時は当月なら今日、それ以外は1日を自動選択。
- PCではカレンダーのセルを拡大し、キャンペーン名を読みやすく表示。
- iPhoneでは従来どおり縦1列表示を維持。
- BONUS+検索・取得エラー/判定保留・PNG保存・PWAなどv0.4.2の機能を維持。

## 既存の判定安全策
- BONUS+全カテゴリ走査。率はページ見出しから動的取得（+4/+5/+9/+10/+15等）。
- カテゴリ取得が一部でも失敗した日は「対象外」にせず判定保留。
- 2026-08-17「TP-Link公式ダイレクト +5%」を回帰ガードに登録。
- 部分一致が複数店に当たる場合は「候補複数」。Yahoo!ストアURL入力ならストアIDで厳密一致。
- LYPプレミアム標準分はカレンダー上に表示しない。

## チャピ側で実施できる試験
Python単体試験、JavaScriptコア試験、構文試験、PWAパッケージ整合性試験、ローカルHTTP配信試験。
実Yahoo!ページをChromiumで全カテゴリ走査する最終ライブ試験はGitHub Actions実行環境で行う設計です。
