# Yahoo! お得日カレンダー v0.6.0

iPhone / Windows 共通の GitHub Pages + GitHub Actions PWA。PC常駐不要です。

## v0.6.0 追加点
- BONUS+一覧ページに実際に掲載されている日付リンクをすべて取得し、固定の日付範囲では切り捨てない。
- 各日付の +5% / +10% / +4% / +9% / +15% 等の率セクションを自動検出。
- 各率セクションにあるカテゴリ選択肢をすべて順番に選び、全ショップ名・ストアURL・ストアIDを統合取得。
- 同一ショップが複数カテゴリに出る場合は categories 配列に所属カテゴリを統合保存。
- 全カテゴリの取得成功数が総カテゴリ数と一致した日だけ status=ok とする。
- 1カテゴリでも失敗した日は status=partial とし、「対象外」判定を禁止。
- 全日付を最大4ページ並列で処理し、従来の networkidle 待ちによる長時間停止を廃止。
- 2026-08-17「TP-Link公式ダイレクト +5%」を回帰ガードとして必須化。

## v0.5.0 までの主な機能
- iPhone / Windows 共通PWA。
- Windowsでは左に月間カレンダー、右に日別詳細の2ペイン表示。
- BONUS+、5のつく日、プレミアムな日曜日、ヤフショ感謝デー等をカレンダー表示。
- LYPプレミアム標準分は表記しない。
- ショップ名またはYahoo!ストアURLで検索。
- PNG画像保存。

## 判定安全策
- 率は固定値ではなくYahoo!ページの見出しから動的取得。
- 取得失敗・解析失敗・カテゴリ不足を「対象外」と扱わない。
- 部分一致で複数ショップに当たる場合は候補複数。ストアURLならストアIDで厳密一致。
- データ更新時はPython単体試験、JavaScriptコア試験、PWA整合性試験、Playwright/ChromiumによるYahoo!ライブ取得試験をGitHub Actionsで実行。
