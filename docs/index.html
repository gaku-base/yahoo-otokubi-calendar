表示ルール

購入金額を入力した場合、カレンダー・TOP3・日付詳細のポイント表示は、通常ポイントを含む合計獲得ポイントです。通常ポイントは標準で7%として「通常ポイント 7%」と明示します。TOP3の順位は、どの日に買っても原則同じ通常ポイントを差し引き、日によって増減するポイント差で判定するため、共通ポイントは順位に影響しません。BONUS+、5のつく日、ファーストデイ、プレミアムな日曜日などの日別特典は、Yahoo!公式の対象ショップ・注文下限・付与上限を反映します。BONUS+対象ショップと公式ボーナスカレンダーは定期更新・手動更新のたびに再取得します。ボーナスストアPlusでさらに+2%は、その日の公式BONUS+対象ショップ一覧に選択ショップが掲載されている場合だけ加算します。プレミアムな日曜日も公式上のBONUS対象ショップと照合します。ヤフショ感謝デーはBONUS対象ショップに加え、設定したヤフショランク（シルバー+4%／ゴールド+5%）を使います。優良ストア+3%やBrand Weekなど、ショップ・商品単位の対象可否を自動確定できない日は「要確認」とし、未確定分を0ptとして扱いません。標準税率10%の商品を前提に税抜相当額を算出し、要エントリー企画はエントリー済、クーポンは使用しない前提です。
