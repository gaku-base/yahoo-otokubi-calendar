表示ルール

カレンダーは日曜始まりです。ポイント計算では、ストアポイント1%・LINE連携3%・LYPプレミアム2%・PayPayクレジット1%の基本7%を標準として加算します。Yahoo!公式ボーナスカレンダーも更新のたびに自動取得し、開催日・還元率・注文下限・付与上限・要エントリーなどを更新します。BONUS+はショップ名またはストアURLで判定し、その日付のYahoo!公式対象ストア一覧に実際に掲載されている場合だけ表示します。「ボーナスストアPlusでさらに+2%」は公式上、当日のBONUS+掲載ストアが対象のため、当日BONUS+対象を確認できたショップだけポイント計算へ加算します。優良ストア+3%・プレミアムな日曜日・ヤフショ感謝デーなど、公式ページだけでは選択ショップの対象可否を確定できない企画は表示してもポイント計算には加えず「判定保留」とします。ヤフショ感謝デーはゴールドランク+5%前提ですが、対象ストア確認時だけ加算します。くじ・抽選や「最大○%」の全体表示は情報として表示し、単純加算しません。要エントリー企画はエントリー済、クーポンは使用しない前提です。予定購入金額は標準税率10%商品の税込額として税抜相当額を算出します。月間上限は当該1回の購入で到達する場合を反映しますが、同月の過去購入分は把握できないため実際の残り上限とは異なる場合があります。
