表示ルール

LYPプレミアムの毎日特典は標準扱いのため表示しません。BONUS+はショップ名またはストアURLで判定し、その日付のYahoo!公式対象ストア一覧に実際に掲載されている場合だけ表示します。全カテゴリーを正常取得できた日で対象ショップ名がない場合はBONUS+対象外として何も表示しません。ショップ名はYahoo!上の正式名称だけでなく、Joshin／ジョーシン、ヤマダ電機／ヤマダデンキなど一般的な表記でも検索できます。複数候補がある場合は候補からショップを選択してください。予定購入金額を入力した場合、お得度TOP3とクリックした日の情報は、確認できたBONUS+と対象可否を確認できるキャンペーンについて、注文下限・付与上限を考慮した概算ポイントで順位付けします。金額は概算用で、実際の対象金額は税抜価格・クーポン利用などにより異なります。「最大○%」や対象ストアか確認できない企画は順位計算へ加えません。
