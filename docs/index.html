表示ルール

カレンダーは日曜始まりです。ポイント計算では、ストアポイント1%・LINE連携3%・LYPプレミアム2%・PayPayクレジット1%の基本7%を標準として加算します。BONUS+対象ショップとYahoo!公式ボーナスカレンダーは定期更新・手動更新のたびに再取得します。ボーナスストアPlusでさらに+2%は、その日付の公式BONUS+対象ショップ一覧に選択ショップが実際に掲載されている場合だけ自動加算します。優良ストア+3%、プレミアムな日曜日、ヤフショ感謝デー、Brand Weekなど、対象ストアかを公式情報だけで確定できない企画はカレンダーには表示しますがポイント計算には加えません。くじ・クーポン等も開催情報として表示できますがポイント計算には加えません。予定購入金額を入力した場合、標準税率10%の商品を前提として税抜相当額を算出し、基本分・BONUS+・対象可否を確認できるキャンペーンの注文下限・付与上限を考慮して概算します。PayPayクレジット1%は税込決済額の200円単位で計算します。要エントリー企画はエントリー済、クーポンは使用しない前提です。月間上限は当該1回の購入だけで上限に達する場合を反映しますが、同月の過去購入分は把握できないため実際の残り上限とは異なる場合があります。「最大○%」は条件を確定できない限り単純加算しません。
